# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository
2. Create a new branch for your changes (`git checkout -b feature-name`)
3. Make your changes and commit them with a clear message
4. Push the branch to your fork (`git push origin feature-name`)
5. Open a pull request describing what you changed and why

## Reporting Bugs

If you find a bug, open an issue and include what you expected to happen, what actually happened, and the steps or input values that caused it.

## Suggesting Enhancements

Have an idea to improve the calculator, like adding compound interest or input validation? Open an issue with the label "enhancement" and describe your suggestion.

## Code Style

Keep the code simple and readable, use meaningful variable names, and add comments where the logic isn't obvious.

## Code of Conduct

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) when contributing to this project.
